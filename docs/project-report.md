# Assignment 2: E-Commerce Landing Page

## Project Name

AURELIA — Premium Fashion and Lifestyle Store

## Introduction

This project is a responsive e-commerce landing page for a fashion and lifestyle store. The page presents the AURELIA brand, introduces the seasonal collection, displays products, and provides simple shopping interactions for a front-end demonstration.

## Technologies Used

- HTML5 for the page structure
- CSS3 for styling, layout, responsive behaviour, transitions, and animations
- JavaScript for filtering, search, product colour selection, cart actions, form validation, and interactive effects
- Bootstrap 5 for the grid system, responsive navigation, buttons, offcanvas cart, and layout components
- Bootstrap Icons for interface icons

## Main Features

The landing page includes a navigation bar, hero section, collection highlights, product cards, testimonials, newsletter form, and footer. A separate Shop page displays the complete collection of twenty products.

The Shop page includes category filters for all products, new arrivals, best sellers, and sale items. The search field uses the complete product catalogue, so a product can be found from either the Home page or the Shop page. Selecting a result opens the Shop page and moves to the matching product.

The product colour controls use separate product images for each colour. This keeps the product shape, background, lighting, and shadows unchanged when a colour is selected. The selected colour is also included in the cart line item.

The page also includes an interactive cart drawer, quantity controls, remove buttons, newsletter validation, scroll-reveal effects, a back-to-top button, product image hover movement, and a subtle desktop card-tilt effect.

## Responsive Design

Bootstrap breakpoints and custom CSS are used so the layout adapts to desktop, tablet, and mobile screen sizes. The navigation collapses on smaller screens, the product grid changes column count, and the hero section rearranges for mobile viewing.
