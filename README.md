# AURELIA E-Commerce Landing Page

AURELIA is a responsive fashion and lifestyle store website created for Assignment 2. The project has a Home page for the main brand presentation and a Shop page containing the full product collection.

## Live website

https://aurelia-ecommerce-landing-page.onrender.com/index.html

## What It Includes

- Responsive navigation and hero section
- Product cards built with the Bootstrap grid
- Filters for all products, new arrivals, best sellers, and sale items
- Search that works across the complete product catalogue
- Separate product images for colour options
- Shopping cart with quantity controls and saved cart data
- Testimonials, newsletter form, and footer
- Hover effects, scroll animations, product image movement, and desktop card tilt
- Mobile-friendly layout

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons

## Running the Project

Open the `public` folder with a local server and visit:

```text
http://127.0.0.1:5500/index.html
```

The Shop page is available at:

```text
http://127.0.0.1:5500/shop.html
```
